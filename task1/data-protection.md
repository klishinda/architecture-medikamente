## Общие категории ПДн пациентов

| Данные | Проблема | Улучшения |
|--------|---------------------------|-------------------|
| ФИО, дата рождения | Прямой идентификатор; связывает все остальные записи о пациенте | псевдонимизация через `patient_uuid`; хранить в отдельной БД |
| Телефон, email | Контактные данные; риск для мошенничества и спама | маскирование (`+7 (XXX) XXX-**-**`); разграничение доступов |
| Адрес прописки, место работы | Расширенные ПДн, нужно согласие | не собирать без необходимости |
| Паспортные данные | высокий риск мошенничества при утечке | маскирование; доступы только для первичного оформления для регистратуры; отдельная БД |
| Согласие на обработку ПДн | Законность обработки данных | отдельная БД с временем согласия и длительностью |
| Суммы платежей, история транзакций | Финансы в файлах - лёгкая доступность, риски изменений, потерь и т.д. | 1С использовать в клиент-серверном режиме; хранить по `patient_uuid`; использовать RBAC |
| Данные договора (номер, стоимость услуг) | конфиденциальность клиента, какими услугами воспользовался | хранится по `patient_uuid`; разграничение доступа |

## Биометрические ПДн

| Данные | Проблема | Улучшения |
|--------|---------------------------|-------------------|
| Сканы подписи | Подделка документов при утечке | Хранение в S3; разграничение доступов; логирование подключений |

## Трудовые ПДн

| Данные | Проблема | Улучшения |
|--------|---------------------------|-------------------|
| ФИО, должность, зарплата | ПДн сотрудников с потенциальным нарушением ТК РФ при утечке | 1С клиент-сервер; разграничение доступов (руководители, hr) |
| Паспорт, СНИЛС, ИНН | Мошенничество, подделка | маскирование; разграничение доступов |
| Трудовые договоры | Содержат разные ПДн + подпись  | хранение в S3; ограниченный доступ; логирование подключений |
| Данные для НДФЛ | содержит общие трудовые ПЛн и передаются вовне | TLS при передаче; доступ ограничен |

## Прочие категории ПДн

| Данные | Проблема | Улучшения |
|--------|---------------------------|-------------------|
| Диагноз, история болезни, хронические заболевания | Риски огласки при утечке | S3 с доступами и логированием; TLS 1.3 при использовании внешних систем; ABAC - только врачи пациента |
| Медицинское заключение, назначения врача | Информация о состоянии здоровья, врачебная тайна | хранение по `patient_uuid` (без ФИО); ABAC - только врачи пациента |
| Результаты анализов | Передача данных между организациями, врачебная тайна| псевдонимизация (`order_id` вместо ФИО, например); mTLS с лабораторией |
| Направления на анализ | Повод обращения + Общие ПДн | Замена ФИО на `order_id` при передаче; TLS |
